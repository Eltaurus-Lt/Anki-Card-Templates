Parameters:

- **reserved keys** - removes associated Anki shortcuts to make the listed keys available for use in card scripts
- **deck styling** - changes the main screen appearance to look closer to Memrise course dashboard (does not affect any styles defined in the user files)
- **thumbnail extensions** - list of image formats enabled for use as deck thumbnails (the shorter the list, the less flickering during deck screen loading)
- **numbered decks** - toggles hiding of ordinal numbers in deck names (can be used to control deck ordering without affecting their displayed titles); also applies the large font style to the numbered deck titles (if *deck styling* is enabled), even when they have no associated thumbnails
